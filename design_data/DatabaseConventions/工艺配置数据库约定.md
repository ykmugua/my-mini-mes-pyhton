# 工艺配置数据库约定

| 项 | 内容 |
|---|---|
| 状态 | 实现版 |
| 日期 | 2026-11-20 |
| 适用范围 | 单线运行；一组件一工艺；工艺可深拷贝派生 |

## 1. 实体关系

- 组件（`products`）绑定一个工艺（`process_code`），**一组件一工艺**。
- 工艺（`processes`）是可复用模板；从已有工艺派生时深拷贝其路线与资源，之后互相独立。
- 被组件引用的工艺禁止删除（只能停用）。

## 2. 表结构（主库 mes.db）

### processes（工艺主表）

| 字段 | 类型 | 说明 |
|---|---|---|
| `process_code` | TEXT PK | 工艺号，唯一 |
| `process_name` | TEXT | 工艺名称 |
| `enabled` | INTEGER | 启用 1/0 |
| `remark` | TEXT | 备注 |
| `source_process_code` | TEXT | 来源工艺号（派生溯源，不做联动） |

### process_routes（工艺工序路线）

| 字段 | 说明 |
|---|---|
| `process_code` | 工艺号 |
| `step_no` | 工序号 |
| `success_next_step` / `fail_next_step` | 成功/失败下站（工序号 / END / LOCK） |

### process_step_resources（工序资源）

| 字段 | 说明 |
|---|---|
| `process_code` / `step_no` | 工艺 × 工序 |
| `program_name` | 该工序使用的程序名 |
| `device_models` | 可执行设备**型号**列表，逗号分隔（该型号下所有设备实例均可执行） |
| `tray_models` | 转运载具**型号**列表，逗号分隔 |

### products.process_code

组件表新增 `process_code`，指向 `processes.process_code`。运行时链路：
`barcode → 组件 → 工艺号 → process_routes / process_step_resources`。

## 3. 已删除的旧表

`product_routes` / `product_step_devices` / `product_trays` / `program_components`
（原按组件实例分配，改由工艺统一配置；程序与组件的关联改由工序资源的 `program_name` 表达）。

## 4. 页面

- 组件注册：组件列表含「绑定工艺」列，新增表单可选择工艺。
- 工艺配置：① 新增工艺（空白 / 派生，深拷贝）② 工艺列表（行选择）③ 工艺详情（工序路线 + 工序资源表：程序下拉 / 设备型号多选 / 载具型号多选）。
- 设备读写记录不再属于本页。
